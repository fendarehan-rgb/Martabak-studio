Cara instal

Android

  1. Unduh file APK.
  2. Izinkan instalasi dari sumber di luar Play Store. Letak pengaturannya berbeda di tiap perangkat.
  3. Buka file APK dan ikuti langkah instalasi.

Windows

  1. Unduh file, lalu jalankan installer atau ekstrak ZIP sesuai formatnya.
  2. Cocokkan hasil checksum dengan SHA-256 di atas. Di Command Prompt, jalankan certutil -hashfile NAMA_FILE SHA256.
